# Sankofa Member Handbook

Member documentation is intended for approved GitHub-authenticated users. Roles are resolved from `platform_members` and enforced by Supabase RLS.

| Role | Scope |
| --- | --- |
| Leads | architecture, releases, protected settings |
| Developers | implementation and pull requests |
| Triage | issue routing and backlog hygiene |
| UAT | acceptance testing and release verification |
| Observers | read-only reporting |

Privileged changes are requested in the member view and executed by protected workflows. Never place service-role keys in a Vite environment variable.
