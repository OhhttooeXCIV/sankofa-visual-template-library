# GitHub governance

The standard teams are Leads, Developers, Triage, UAT, and Observers. Every generated repository receives one Project V2 board named after the project, statuses `ToDo`, `In Progress`, `Review`, `In Review`, `Rejected`, and `Done`, plus the common labels listed in the generator reference.

The CLI supports dry-run planning first. Applying organization changes requires a GitHub App or fine-grained token with only the scopes needed for the selected operation.
