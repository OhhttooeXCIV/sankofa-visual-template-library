# Installation

The current repository is the reference showcase. Published consumers can install the versioned packages:

```bash
npm install @sankofa/ui @sankofa/contracts @sankofa/config
```

For a new application:

```bash
npx create-sankofa-app create my-project --dry-run
```

Generated applications pin package versions and include a lockfile, environment template, caller workflows, and a validation script.
