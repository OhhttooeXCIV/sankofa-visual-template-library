Security and reuse boundaries

Public packages contain generalized UI, contracts, and safe adapters only. Emergency dispatch, survivor profiles, covert camouflage, encrypted evidence vaults, duress triggers, and related Umk product flows are not exported from the generic platform.

Member operations are request-based. The browser may create a request, but protected GitHub Actions perform privileged changes using scoped credentials. Secrets must never appear in public documentation, frontend bundles, or CLI logs.
