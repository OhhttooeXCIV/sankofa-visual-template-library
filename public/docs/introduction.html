Sankofa Digital Library

Sankofa is a lightweight, reusable foundation for React/Vite products. It gives teams a coherent UI language, typed service contracts, Supabase-ready backend patterns, and production workflows without forcing every product into one domain.

Start here

1. Browse the public component catalog in the library app.

2. Install the packages you need, or run sankofa create <project-name>.

3. Keep domain-specific logic in the application repository and use the library for stable primitives, contracts, and adapters.

The platform is intentionally static-first: Vite builds the frontend, Vercel serves it globally, and Supabase provides the isolated backend for each generated application.
